## 3. Current-state self-model

The current system is a local evidence-producing modular prototype:

`capture -> segment -> normalize -> template -> observe -> candidates -> targeted discriminator -> fuse -> decide -> inventory`

It has a useful safety posture: raw evidence is retained, writes are bounded,
and the sample ended with nine `AMBIGUOUS` decisions rather than false
confirmations. It does not yet possess the target architecture's full
capability graph.

## 5. Transition portfolio and critical path

1. Freeze governance, schemas, version registry, and evidence contracts.
2. Establish reviewed fixtures, permitted media manifests, and a benchmark
   truth protocol.
3. Expand corpus ingestion and canonical printing/variant model.
4. Implement geometry, derivatives, anchors, and quality evidence.
5. Build hierarchical template taxonomy, registry, classifier, and calibration.
6. Build semantic-zone localization with template priors, anchors, detector
   proposals, and candidate-conditioned alternatives.
7. Expand typed extractors and preserve raw alternatives, failure modes, and
   provenance.
8. Implement candidate retrieval, active discriminator planning, comparison,
   fusion, abstention, human review, and superseding assertions.
9. Add benchmark, calibration, drift, reproducibility, and operational gates.
10. Conduct independent review and lifecycle decision.

Critical path: **T1 contracts -> T2 truth fixtures -> T3 corpus model -> T4
geometry/anchors -> T5 classifier/registry -> T6 zone localization -> T7
extractors -> T8 reasoning/fusion -> T9 benchmark/calibration -> T10 review**.

No downstream accuracy claim is valid until T2 and T9 exist.

## 6. Observation and replanning contract

At each milestone, record the exact code commit, registry versions, corpus
snapshot, fixture set, model/data versions, environment, command, outputs,
metrics, reviewer, and unresolved conditions. Re-plan when any of these occurs:

- a benchmark falsifier is triggered;
- a required source or rights assumption changes;
- a schema or invariant changes;
- confidence calibration fails its gate;
- a decision boundary is crossed (new scope, external release, or service
  decomposition);
- no material delta is achieved for two review cycles.

gates in the target architecture and an authorized lifecycle decision records
