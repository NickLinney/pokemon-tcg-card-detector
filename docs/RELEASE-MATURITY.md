# Release and Maturity Disposition

Status: **Pre-Alpha 1 vertical slice, locally validated, unreleased**.

The implementation is suitable for continued engineering and reviewed fixture
work. It is not suitable for unattended inventory truth, authentication,
grading, commercial valuation, or a production service.

No release tag or GitHub release has been created. Independent security, QA,
licensing, and release acceptance have not occurred, so validation evidence
must not be interpreted as promotion. The missing GitHub credential is a
publication blocker only; it does not invalidate the local implementation or
its immutable evidence.

Next justified gate: add reviewed sample ground truth and permitted reference
images, measure top-k and false-confirmation behavior on a larger fixture set,
resolve OCR-model redistribution terms, and conduct independent review before
any release proposal.
