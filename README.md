# Pokémon TCG Card Detector

Evidence-preserving, local-first pre-alpha pipeline for decomposing nine-pocket
binder photographs into ordered card observations, local catalogue candidates,
and qualified identification decisions.

This repository is an experimental vertical slice. It does **not** claim broad
historical coverage, grading, authentication, production readiness, or reliable
automatic identification beyond measured fixtures. Unknown, ambiguous,
conflicting, and insufficient-evidence results are intentional outcomes.

Implementation and run instructions are added on the active feature branch.

## Lifecycle

- repository state: bootstrap
- implementation target: Pre-Alpha 1 vertical slice
- release state: not released
